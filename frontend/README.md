# TikTak Real Estate — Icyiciro cya 6

Iki cyiciro gikomeza ibyiciro 1–5 kandi cyongeramo:
- Gukurikirana amasezerano: Interested → Negotiation → Sale Agreement → Sale Completed; harimo Disputed.
- Guhindura intambwe y'igurisha muri Admin.
- Ibariro rya komisiyo ya 5% ku giciro cyose, mu RWF cyangwa KES.
- Urutonde rw'intambwe zo kugenzura no kwandika ubwishyu bwa komisiyo.

## Gufungura
Kuramo ZIP, ukore Extract All, ufungure folder `tiktak-stage6`, hanyuma ukande `index.html`. Fungura `admin.html` kugira ngo ukoreshe ibikoresho bishya bya Admin.

## Icyitonderwa gikomeye
Iyi ni prototype ya front-end. Amasezerano n'impinduka zibikwa muri browser imwe gusa. Nta masezerano yemewe mu mategeko, nta Mobile Money/bank integration, kandi nta mafaranga yakirwa cyangwa yemezwa na sisitemu. Kwemeza komisiyo nyayo bisaba kugenzura ubwishyu no gusuzuma amasezerano n'amategeko akurikizwa mu Rwanda no muri Kenya.
